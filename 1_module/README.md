# 챕터 1 — 모듈 사용법

import · export · default export로 코드를 여러 파일로 나눠 봅니다. 인터넷 연결 없이 실행됩니다.

- 수업 시간: 수업 실습 8교시
- 실행: 레포 최상위 폴더에서 `node <폴더>/starter/main.js`

| 구분 | 폴더 | 내용 | 권장 시간 |
|---|---|---|---|
| 수업 실습 | `step1_import-export` | [실습-1] import와 export | 10분 |
| 수업 실습 | `step2_default-export` | [실습-2] default export | 8분 |
| 수업 실습 | `step3_split-modules` | [실습-3] 모듈 분리하기 | 20분 |

## [실습-1] import와 export

**실습 목표:** 필요한 것을 내보내고 다른 파일에서 가져옵니다.

- 폴더: `1_module/step1_import-export/starter` · TODO 주석을 따라 코드를 완성합니다.
- 실행: `node 1_module/step1_import-export/starter/main.js`

**예상 결과**

```
3.14
4
```

## [실습-2] default export

**실습 목표:** default export한 함수를 원하는 이름으로 가져옵니다.

- 폴더: `1_module/step2_default-export/starter` · TODO 주석을 따라 코드를 완성합니다.
- 실행: `node 1_module/step2_default-export/starter/main.js`

**예상 결과**

```
3.14
4
```

> 풀이는 수업 시간에 슬라이드로 함께 봅니다.

## [실습-3] 모듈 분리하기

**실습 목표:** 파일 하나에 몰린 코드를 기능별 모듈로 나눕니다.

- 폴더: `1_module/step3_split-modules/starter` · TODO 주석을 따라 코드를 완성합니다.
- 실행: `node 1_module/step3_split-modules/starter/main.js`

**예상 결과**

```
김코드 90%
이자바 100%
박노드 75% (출석 관리 필요)
```

> 풀이는 수업 시간에 슬라이드로 함께 봅니다.
